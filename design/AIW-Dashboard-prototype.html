Project Overview

JAME System Dual is a dual-output educational content engine.

It has two major outputs:

  • Web lessons.
  • Slide lessons.

This project console tracks:

  • roadmap state,
  • run queue,
  • documentation state,
  • review policy,
  • human QA state,
  • AIW integration.

Architecture Summary

The "Parallel" instance isolates experimental changes to component boundaries before backporting to canonical state. Each component maintains contractual autonomy — changes do not cascade to the global renderer without an explicit architecture run.

Current Operating Model

This project operates in external manual mode. AIW reads but does not write to the repository. All commits originate from external tooling or human action. The project console provides a read-only view of the current state.

How AIW Interacts With This Repo

AIW reads from .aiw/ directory structures seeded by human-driven commits. It cannot trigger runs, push commits, or modify state files. The roadmap and run queue are informational views derived from static JSONL sources.

What Not to Touch

Do not modify JAME_Lessons content without explicit approval. Schema and compiler changes require a dedicated architecture run — they must never be coupled with UI or styling tickets.
